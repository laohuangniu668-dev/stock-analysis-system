# 个人简化投研平台

## 🎯 项目定位

本项目是一个**面向个人小散户的简化投研平台**，以 Excel/CSV 自选股文件作为唯一驱动源，支持策略回测、组合管理、风险控制和投资决策支持。

### 核心理念
- ✅ **数据准确优先** - 本地历史数据库，增量更新，避免重复下载
- ✅ **配置驱动** - 所有参数从 Excel 读取，无需改代码
- ✅ **风险控制优先** - 止损、止盈、仓位、集中度，全面管理
- ✅ **可理解的输出** - 清晰的报告、建议、指标，不是黑箱
- ✅ **学术简化落地** - Markowitz、CAPM、Kelly、风险平价等理论的散户友好实现

## 🚀 快速开始

### 1. 安装依赖

**Linux/Mac:**
```bash
sh install.sh
```

**Windows:**
```cmd
install.bat
```

### 2. 启动 Web 应用

**Linux/Mac:**
```bash
sh run_web.sh
```

**Windows:**
```cmd
run_web.bat
```

然后访问：**http://localhost:8501**

### 3. 使用流程

1. **上传自选股文件** - Excel/CSV 格式
2. **配置回测参数** - 初始资金、日期范围
3. **运行分析** - 自动回测、计算指标、生成建议
4. **查看结果** - 收益、风险、持仓、评级
5. **下载报告** - Excel、JSON、CSV、文本格式

## 📋 自选股文件格式

**必需列：**

| 列名 | 说明 | 示例 |
|-----|------|------|
| 代码 | 股票代码 | 000001 |
| 名称 | 股票名称 | 平安银行 |
| 市场 | A股/港股 | A / HK |
| 启用 | 是否启用 | 是 / 否 |
| 策略 | 使用策略 | dual_ma / macd |
| 参数1-5 | 策略参数 | 5, 20, ... |
| 目标权重 | 目标权重 | 0.2 |
| 最大仓位 | 单票最大 | 0.3 |
| 止损 | 止损比例 | 0.08 |
| 止盈 | 止盈比例 | 0.15 |
| 备注 | 说明 | 核心持仓 |

**示例：**

```csv
代码,名称,市场,启用,策略,参数1,参数2,参数3,目标权重,最大仓位,止损,止盈,备注
000001,平安银行,A,是,dual_ma,5,20,,0.20,0.30,0.08,0.15,核心持仓
600519,贵州茅台,A,是,dual_ma,5,20,,0.15,0.25,0.08,0.15,消费龙头
00700,腾讯控股,HK,是,macd,12,26,9,0.25,0.30,0.10,0.20,港股科技
```

## 🎨 Web 应用功能

### 📊 上传文件
- 拖拽或选择 CSV/Excel 文件
- 自动预览和验证
- 提供模板下载
- 显示启用股票数统计

### 📈 分析结果
- 投资评级（STRONG BUY / BUY / HOLD / SELL）
- 收益、夏普比、最大回撤、波动率等关键指标
- 详细的账户、收益、风险指标
- 交易记录和当前持仓显示

### ⚠️ 风险控制
- 持仓权重分析
- 集中度风险检查
- 投资计划和建议
- 详细的投资建议文本

### 📥 下载报告
- Excel 报告（汇总表 + 交易明细 + 持仓）
- JSON 数据（完整回测数据）
- CSV 交易记录
- 文本报告（格式化分析）

## 📊 支持的策略

### dual_ma - 双均线策略
- 参数：短周期、长周期
- 信号：金叉买入，死叉卖出

### macd - MACD 策略
- 参数：fast、slow、signal
- 信号：MACD 穿越信号线

## 📈 关键指标

| 指标 | 说明 | 优秀值 |
|-----|------|--------|
| 夏普比率 | 风险调整收益 | > 1.0 |
| 最大回撤 | 最大亏损幅度 | > -0.15 |
| 波动率 | 年化波动率 | < 0.2 |
| 年化收益 | 年化收益率 | > 0.1 |

## 🛠️ 命令行版本
